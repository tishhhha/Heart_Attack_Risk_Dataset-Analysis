# ❤️ Heart Attack Risk Prediction System

> A full-stack machine learning web application for real-time cardiovascular risk assessment, built entirely in Python using Flask and scikit-learn.

---

## 📋 Project Overview

This project performs end-to-end analysis and modelling on a 20,000-record clinical dataset to predict the risk of a heart attack. It covers:

- **Data Quality Assessment** — missing value detection, duplicate checks, outlier analysis, and logical consistency validation
- **Exploratory Data Analysis (EDA)** — 12 statistical charts covering demographics, vitals, lifestyle factors, comorbidities, and correlations
- **Machine Learning** — Random Forest classifier with StandardScaler preprocessing, achieving high accuracy and ROC-AUC score
- **Web Application** — Flask-based app with embedded Bootstrap 5 UI, live EDA dashboard, model performance page, and a REST API endpoint

## 🚀 Features

- **Patient Risk Prediction Form** — 30-field intake form grouped by category (demographics, vitals, lab results, lifestyle, medical history/symptoms)
- **Colour-coded Risk Output** — 🔴 High Risk / 🟡 Moderate Risk / 🟢 Low Risk with clinical advice
- **Live EDA Dashboard** (`/eda`) — 5 interactive charts rendered from the real dataset on startup
- **Model Performance Page** (`/model_info`) — accuracy, ROC-AUC, classification report, confusion matrix
- **Dataset Info Page** (`/dataset_info`) — key statistics and live record preview
- **REST API** (`/api/predict`) — JSON endpoint for programmatic predictions
- **Standalone EDA Script** (`eda_analysis.py`) — generates 12 chart files to `eda_output/`

## ⚙️ Setup & Run Instructions

### 1. Prerequisites

- Python 3.10 or higher
- pip package manager
- The dataset file (`heart_attack_risk_dataset_20k.csv`) in the project root

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run Standalone EDA (Optional)

Runs data quality checks and saves all 12 EDA charts to `eda_output/` — no web server started:

```bash
python main.py --eda
```

### 4. Run the Web Application

```bash
python main.py
```

On startup the app will:
1. Load the dataset and run data quality checks
2. Save all 12 EDA charts to `eda_output/`
3. Train the Random Forest model (~10–15 seconds)
4. Build in-memory EDA charts for the web dashboard
5. Start the Flask server

Then open your browser at:

```
http://localhost:5000
```

### 5. Application Routes

| URL | Description |
|---|---|
| `http://localhost:5000/` | Patient prediction form |
| `http://localhost:5000/eda` | EDA Dashboard |
| `http://localhost:5000/model_info` | Model performance metrics |
| `http://localhost:5000/dataset_info` | Dataset statistics & preview |
| `http://localhost:5000/api/predict` | REST API (POST, JSON body) |

## 📊 Key Findings

1. **Hypertension is the most prevalent risk factor** — present in 58.5% of patients
2. **Previous heart disease is the strongest single predictor** of future cardiac events
3. **Age moderately correlates with risk**, especially after age 55
4. **Lifestyle factors matter** — poor diet + low activity + high stress significantly elevate risk
5. **Elevated CRP (>3 mg/L)** is concentrated in the high-risk group, confirming inflammation's role
6. **Dataset quality is excellent** — zero missing values, zero duplicates, all values clinically plausible
